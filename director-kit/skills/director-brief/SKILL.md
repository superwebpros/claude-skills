# Director Brief — Stage 1

**idea / source story → creative brief.** Translate intent into a structured brief so every later stage has a spine. The user need not know filmmaking — that's the kit's job.

Pipeline: **director-brief → director-assets → director-shotlist → director-storyboard → director-animate**

## 1. Pick the content profile (this shapes everything)
Read `references/content-profiles.md` and choose: **story-adaptation · ad · short/reel · trailer.** The craft is identical across all; the profile only changes framing (goal, structure, CTA, what the dramatic object is). If it's an ad/short, also read the project's `project-context.md` (brand/product/audience) if present; if it's missing, offer to create one from `references/project-context.template.md`.

## 2. Load craft references (pull what the profile needs)
- `references/story-frameworks.md` — structure, conflict, logline formula.
- `references/format-recipes.md` — the skeleton for the chosen format.
- `references/continuity.md` — **§ Dramatic-object extraction** (do this here).
- `references/directors-eye.md` — the intent checklist (run the brief against it).

## 3. Intake — get just enough, then move
Propose and let the user correct; don't interrogate. Need: profile, format & length, the core angle/source, subject, any must-include line/CTA, and the **world/period** (when/where is this set?). For a story adaptation, the source text IS most of the intake.

## 4. Extract the dramatic object(s)
Per `continuity.md`: name the object(s) of value / MacGuffin and its **arc** (coveted → endangered → saved, etc.). This is mandatory — it's what gives stakes and lets a twist land.

## 5. Write the brief
```
# Brief: [title] — [profile, format, length]
## Content profile: [story-adaptation | ad | short | trailer]
## World / period: [era + the lighting/prop rules it implies]
## Logline / central question
## Audience & tension
## The turn / withhold        ← the promise (ad) OR the source's twist (story) OR the teased question (trailer)
## Dramatic object(s) + arc   ← from step 4
## Tone & feel
## Beat sheet (anti-sag)       ← every beat escalates or reveals; cut any that only "set up"
## CTA / soft-CTA / title card ← per profile
```

## Finish
1. Run it against the Director's Intent checklist (`directors-eye.md`).
2. Save to `creatives/<slug>/brief.md` (create the folder).
3. Offer next: "Lock the cast, props, locations & world for this? → **director-assets**."
