# Worked example: reading a run in its first $230

A $497 course sold **direct to the sales page**, Meta purchase optimisation, ~$107/day, two video ads each with a 9:16 and a 4:5 version. Compared against an earlier **lead-gen quiz** run of the same brand (lead optimisation).

## Day 1–2: what the numbers said

| | Quiz run, first $206 | Course run, first $204 |
|---|---|---|
| Cost per 1,000 impressions | $135 | $68 |
| 3-second view rate | 27% | 21% |
| ThruPlay rate | 8.7% | 4.6% |
| Link CTR | 1.83% | 0.57% |

Naive read: "the course ads are much worse, pause them." The commentary bot said exactly that at $103 spent.

## The like-for-like read

By placement, the quiz run **never ran Facebook feed**; the course run gave it 40% of impressions:

| Placement | Quiz 3s / CTR | Course 3s / CTR |
|---|---|---|
| Facebook Reels | 33% / 0.78% | 30% / 0.73% |
| Instagram feed | 28% / 1.67% | 30% / 0.67% |
| Instagram Reels | 28% / 1.82% | 25% / 0.44% |
| Instagram Stories | 12% / 1.40% | 11% / 1.90% |
| Facebook feed | — | **15% / 0.17%** (2 clicks) |

Without Facebook feed the course run was ~25% hook / ~0.85% CTR: the creative holds attention about as well; one placement dragged the average. Stories' high CTR with an 11% hook and only 5 of 12 clicks loading the page = accidental taps.

Video retention showed the hook, not the body, was the leak: of viewers reaching 25%, 65% reached 50%.

## Decisions logged (each with a read point)

1. **Opening variant**: new versions that open on the presenter full-frame, original kept as control. Read at ~$350: v2 wins if 3s rate ≥ 27% and FB feed ≥ 22%, CTR not lower.
2. **Pause the weak second ad** (20% hook, 3.3% ThruPlay, 1 click on $19).
3. **Drop Facebook feed** instead of pausing ads. Read at ~$350.
4. **Hold the funnel** (direct vs quiz-first) until the $500 checkpoint; the quiz route only wins if ~1 in 10 leads buys.

## What went wrong without the method

- Day 2 commentary: "pause the underperforming variants immediately" — about v2 ads with ~$20 each, under test until $350. A new ad beside an incumbent gets starved by the platform (03 v1 got 3.5× v2's spend on day 1), so it was unread, not losing.
- On day 1 the v2 opening looked worse in Facebook feed (12% vs 18%) on 186 impressions — inside the noise, and in the placement already flagged for removal.
